<b> <h2> >Here are the Steps how to start this project/app of Micronotes. </b></h2>

<h3>To run the frontend-> Go to the Project directory that is named 'Client' using these steps-</h3><br>
1- cd client<br>
2- npm run dev (type this command to run the frontend server made using React)<br>
3- once the dev server is started, follow the default URL http://localhost:5173/ to see the Micronotes app.<br>

<h3>To start the backend-> Go to the server folder using these steps-</h3><BR>
1- cd .. (to go back to root directory)<br>
2- cd server<br>
3- node server.js (type this command to run the backend server made using Node.js)<br>
4- once the server is ON, you can see a message printing on the terminal like Server running on port 5000 which means the backend server is running fine.<br>
